# HTML Basics Assignment

A simple project demonstrating core HTML concepts and elements.

## Description
This assignment focuses on building a static webpage using foundational HTML elements. The goal is to practice structuring content, using semantic tags, and applying best practices for accessibility and readability.

## Features
- Proper HTML document structure with `<!DOCTYPE>`, `<html>`, `<head>`, and `<body>`.
- Semantic elements like `<header>`, `<nav>`, `<main>`, and `<footer>`.
- Lists (`<ul>`, `<ol>`, `<li>`), headings (`<h1>` to `<h6>`), and paragraphs (`<p>`).
- Links (`<a>`), images (`<img>`), and tables (`<table>`, `<tr>`, `<td>`).
- Forms with input types (`<input>`, `<textarea>`, `<button>`).
- Comments (`<!-- -->`) for code clarity.
- Meta tags for responsiveness (e.g., `viewport`).

  
## What I Learned
- The importance of semantic tags for SEO and accessibility.
- How to structure content hierarchically with headings (`<h1>` to `<h6>`).
- Best practices for image accessibility using the alt attribute.
- Form validation with HTML5 input types (email, number, etc.).
- Writing clean, readable code with comment
