# Assignment 4: Bootstrap Website
## Description
A responsive multi-page website built with HTML, CSS, and Bootstrap 5 featuring Home, Contact, FAQ, and other sections.
## Bootstrap Components Used:
- Responsive navbar with toggle and scrollspy
- Card grids for content
- Pre-styled forms (Contact page)
- Accordion (FAQ page)
- Utility classes for spacing & layout
## Customizations:
- Overridden Bootstrap colors/variables
- Added custom CSS for unique elements
- Optimized mobile responsiveness
## What I Learned
-  Bootstrap Grid System (container, row, col-*)
- Reusable Components (cards, navbars, modals)
- Utility-First Workflow (vs. writing custom CSS)
- Mobile-First Development (breakpoints, hiding elements)
- Official Documentation Navigation
