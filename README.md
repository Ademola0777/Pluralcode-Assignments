# CSS Practice: Profile Card and Product Card 
Two responsive card components (product + profile) built to master fundamental and modern CSS techniques.

## Description
Practiced core CSS concepts by building two responsive card components:
1. **Product Card** (with price and button)
2. **Profile Card** (with avatar and social links)

## Key Features
- **Product Card**
  - Hover effects on interactive elements
  - Responsive pricing layout
  - Clean typography hierarchy

- **Profile Card**
  - Circular avatar using `border-radius`
  - Flexbox social links
  - Subtle box shadows for depth

## What I Learned
- **Layout**: Flexbox/Grid for component structuring
- **Styling**: CSS variables for consistency
- **Effects**: Transitions and hover states
- **Images**: `object-fit` and aspect ratio control
- **Responsiveness**: Relative units (`rem`, `%`)
