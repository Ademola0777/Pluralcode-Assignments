# Assignment 3: Portfolio Website

## Project Description
A responsive personal portfolio website built with **HTML** and **CSS** to showcase projects and skills. Focused on proper document structure, semantic markup, and modern styling techniques.

## Key Features
- **Semantic HTML5** (`<header>`, `<section>`, `<footer>`)
- **Mobile-first responsive design** (media queries)
- **Interactive elements** (hover states, navigation)
- **Project showcase grid** (Flexbox/Grid layout)
- **Clean typography** (Google Fonts)

## What I Learned
- Proper HTML structure for accessibility
- CSS positioning (Flexbox/Grid)
- Responsive design principles
- Project organization (file structure)
- Debugging techniques (Chrome DevTools)
